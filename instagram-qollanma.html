Dasturchi uchun

Server tekshiruvi

Mac terminalida, loyiha papkasida (~/Projects/sotuvchi-ai) ishga tushiriladi. Hech biri token yoki parolni chiqarmaydi. Har biri ostida sog'lom holatdagi namunaviy natija berilgan.

1. Server ishlayaptimi

Konteynerlar, tunnel protokoli va api javobi.

docker compose -p sotuvchi-tunnel ps
docker logs sotuvchi-tunnel-tunnel-1 2>&1 | grep -E "Registered|ERR" | tail -6
curl -s -o /dev/null -w 'api %{http_code}\n' https://api.najotsoft.uz/health
Yaxshi natija 
… INF Registered tunnel connection connIndex=3 … location=waw03 protocol=http2
… INF Registered tunnel connection connIndex=2 … location=waw06 protocol=http2
api 200

Yomon belgi: ko'p ERR … failed to dial to edge with quic yoki Unable to reach the origin service. Ikkinchisi faqat api qayta ishga tushayotganda normal.

2. Meta nima yuboryapti

Kelgan webhook'lar, Meta fayl yuklab olishlari, ulash ogohlantirishlari.

docker logs --since 1h sotuvchi-tunnel-api-1 2>&1 \
  | grep -E "instagram webhook|file link|Direct messages will not arrive|Instagram token|signature" \
  | tail -20
Yaxshi natija 
… [ChannelsService] instagram webhook: 1 entry for 17841…
… [FilesController] file link served: image/png 617060 B GET ua=facebookexternalhit/1.1 …

Yomon belgi: Direct messages will not arrive (sahifa obunasi yo'q), signature mismatch (ilova siri noto'g'ri), file link refused (havola eskirgan).

3. Nega yuborilmadi

Paneldan ketmagan xabarlarning sababi.

docker logs --since 1h sotuvchi-tunnel-worker-1 2>&1 | grep -iE "outbound|failed" | tail -10
